# Navegação e produtividade

## Navegação

Zen é o navegador principal, instalado de forma isolada do sistema. Sua aparência acompanha o tema dinâmico do desktop e permanece totalmente opaca quando sem foco. Perfis, logins, extensões, abas e histórico não são restaurados por este repositório.

## Arquivos, documentos e leitura

- Dolphin é o gerenciador de arquivos padrão.
- Yazi oferece navegação de arquivos no terminal.
- Ark, Gwenview e Haruna cobrem compactação, imagens e vídeo leve.
- OnlyOffice é a suíte de documentos; Calibre cobre e-books.
- O manipulador padrão de PDF é Stirling PDF; o conteúdo de documentos fica fora do escopo.
- Meld oferece comparação visual de arquivos e diretórios.

## Organização pessoal

Obsidian está disponível para notas locais. Actual Budget está disponível como aplicação isolada para finanças pessoais. Seus cofres, bancos de dados, contas e conteúdo são dados pessoais e não pertencem à reconstrução declarativa.

## Utilitários

Incluem calculadora, captura e anotação visual, imagem de sistemas para Raspberry Pi, gerenciador de torrents, cliente FTP e aplicações de busca/gestão de partições. A presença dessas ferramentas deve ser preservada quando houver alternativa funcional adequada na distribuição de destino.
