# Terminal e desenvolvimento

## Terminal e shell

Kitty é o terminal padrão. Usa JetBrains Mono Nerd Font em 11 pt, padding confortável, cursor em barra com piscar curto, sem sino sonoro e atalho interno para consultar o scrollback. Fish é o shell interativo preferido; a função de abrir Yazi deve retornar ao diretório escolhido pelo gerenciador de arquivos.

Konsole permanece disponível como terminal alternativo. Neovim e Vim existem como editores de terminal; Kate como editor gráfico leve.

## Ambiente de desenvolvimento

Visual Studio Code e VSCodium são editores gráficos disponíveis. A experiência compartilhada privilegia fonte JetBrains Mono Nerd Font em 16 pt, ligaduras, minimapa desativado, formatação ao salvar e colar, remoção de espaços finais, sugestões inline, Git com autofetch e confirmação reduzida para operações de rotina.

O editor inicia sem arquivo de boas-vindas, usa a barra lateral à direita e abre arquivos não confiáveis em vez de bloqueá-los. Para Python, pytest é o padrão de testes, análise de tipos é básica e a organização de imports fica disponível no salvamento explícito.

## Ferramentas e runtimes

O ambiente mantém Git e GitHub CLI, Python, Node/Bun, Rust, CMake, Ninja, Lua, ferramentas de contêiner e Podman Desktop. Também inclui ferramentas de diagnóstico e inspeção de disco, rede, hardware e processos, como Btop, Fastfetch, Glances, Duf, Ncdu e Filelight.

OpenCode e o cliente Codex fazem parte do ambiente de assistência por IA. Um gateway local OpenClaw é um serviço de usuário separado; suas credenciais e sua configuração operacional não são documentadas aqui.
