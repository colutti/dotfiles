# Steam HDR Gaming Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Persist 4K 10-bit HDR on DP-2 and provide a safe per-game Steam Gamescope/MangoHud launch path.

**Architecture:** Restore the repository's previously validated desktop mutation CLI so that monitor changes use a 20-second confirmation transaction. Make the typed settings and Hyprland declarations permanently HDR on DP-2, add a stowable MangoHud configuration, and document the official CachyOS `game-performance` launcher ordering. The current checkout is intentionally used because the active desktop symlink points to it and the user explicitly authorized implementation there.

**Tech Stack:** Python 3 standard library, Bash, Lua/Hyprland 0.56, MangoHud 0.8, Gamescope 3.16, Steam/Proton-CachyOS.

---

### Task 1: Restore the monitor transaction boundary

**Files:**
- Create: `desktopctl/colutti_desktopctl.py`
- Create: `bin/colutti-desktopctl`

- [ ] **Step 1: Restore the last repository version that contained the validated monitor transaction**

Use the historical source from commit `7b80887`, which contains `MonitorManager.apply`, `confirm`, `rollback`, and DP-2-only HDR control. Restore it with an `apply_patch` patch generated by:

```bash
git diff -R 7b80887 -- desktopctl/colutti_desktopctl.py bin/colutti-desktopctl
```

- [ ] **Step 2: Verify the command exposes the transaction interface without changing monitor state**

Run:

```bash
python -m py_compile desktopctl/colutti_desktopctl.py
COLUTTI_DESKTOP_ROOT="$PWD" ./bin/colutti-desktopctl monitors --help
```

Expected: exit 0 and `apply`, `confirm`, `rollback`, and `hdr` actions are listed.

### Task 2: Persist the HDR and overlay configuration

**Files:**
- Modify: `settings/default.json`
- Modify: `hyprland/.config/hypr/modules/monitors.lua`
- Create: `mangohud/.config/MangoHud/MangoHud.conf`
- Modify: `install.sh`

- [ ] **Step 1: Change the source-of-truth DP-2 fields**

Set only DP-2's `bitdepth` to `10` and color mode/`cm` to `hdr`. Preserve its mode, position, scale, and VRR off; preserve every HDMI-A-1 field.

- [ ] **Step 2: Add the global MangoHud configuration**

Create the stow package `mangohud` with a compact, 4K-readable configuration that reports frame timing, FPS percentiles, hardware thermal/power/load, memory, HDR and refresh status, and has non-invasive toggle hotkeys. Do not set scaling, FPS limiter, HDR inverse tone mapping, or an automatic launch wrapper in the global environment.

- [ ] **Step 3: Link the stow package**

Add `mangohud` to `config_packages` in `install.sh` so `./install.sh link` manages `~/.config/MangoHud/MangoHud.conf` without touching Steam libraries or the running Steam process.

### Task 3: Validate and apply the monitor transaction

**Files:**
- Modify: `README.md`
- Modify: `docs/hardware.md`
- Modify: `docs/architecture.md`
- Modify: `docs/recovery.md`

- [ ] **Step 1: Document permanent HDR and recovery**

Document DP-2 HDR/10-bit permanence, SDR recovery, capture limitation, lack of VRR, `game-performance` over GameMode when `ananicy-cpp` is active, and the exact Steam option:

```bash
DXVK_HDR=1 game-performance gamescope -f -W 3840 -H 2160 -w 3840 -h 2160 --hdr-enabled --mangoapp -- %command%
```

- [ ] **Step 2: Run offline validations**

Run:

```bash
python -m json.tool settings/default.json >/dev/null
python -m py_compile desktopctl/colutti_desktopctl.py
Hyprland --verify-config -c "$PWD/hyprland/.config/hypr/hyprland.lua"
./install.sh validate
```

Expected: all commands exit 0.

- [ ] **Step 3: Apply and confirm HDR visually**

First update the user settings JSON with the HDR DP-2 fields, then run:

```bash
COLUTTI_DESKTOP_ROOT="$PWD" colutti-desktopctl monitors apply --timeout 20
```

During the 20-second window, confirm a usable HDR image and run:

```bash
COLUTTI_DESKTOP_ROOT="$PWD" colutti-desktopctl monitors confirm <token>
hyprctl monitors all
```

Expected: DP-2 reports `XRGB2101010` and HDR color management; HDMI-A-1 remains SDR/8-bit and VRR remains disabled. If the image is not usable, wait for automatic rollback or run `colutti-desktopctl monitors rollback` from a TTY.
