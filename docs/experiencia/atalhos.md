# Atalhos

`SUPER` é a tecla Mod. Os atalhos abaixo são globais, salvo quando sua ação exige uma janela com foco.

## Aplicações e painéis

| Combinação | Resultado |
| --- | --- |
| Super + Enter | Abre o Kitty |
| Super + E | Abre o Dolphin |
| Super + Espaço | Abre o launcher de aplicações |
| Super + V ou Super + Shift + V | Abre o histórico de clipboard |
| Super + N | Abre a central de notificações |
| Super + Vírgula, Super + I ou Super + Q | Abre ou foca as configurações do desktop |
| Super + M | Abre ou foca a lista de processos |
| Super + Y | Abre o navegador de wallpapers |
| Super + L | Bloqueia a sessão |
| Super + O | Mostra a ajuda de atalhos |
| Super + P | Abre o menu de energia |
| Super + Shift + H | Abre a calibração HDR |
| Print Screen | Copia uma captura de região para o clipboard |

## Janelas, foco e monitores

| Combinação | Resultado |
| --- | --- |
| Alt + Q ou Super + C | Fecha a janela ativa |
| Super + F | Alterna tela cheia |
| Super + Shift + F | Alterna janela flutuante |
| Super + setas | Move o foco entre janelas |
| Super + Shift + setas | Move a janela ativa |
| Super + Alt + setas | Redimensiona a janela ativa em incrementos pequenos |
| Control + Super + Cima | Foca o monitor principal |
| Control + Super + Baixo | Foca o monitor secundário |
| Control + Super + Esquerda/Direita | Muda para o espaço anterior/seguinte |
| Super + roda do mouse | Muda de espaço de trabalho |
| Super + botão esquerdo/direito do mouse | Arrasta/redimensiona a janela ativa |
| Botões laterais do mouse | Muda de espaço de trabalho |

## Espaços e mídia

| Combinação | Resultado |
| --- | --- |
| Super + 1 a 8 | Foca o espaço correspondente |
| Super + Shift + 1 a 8 | Move a janela ativa para o espaço correspondente |
| Teclas de volume | Ajustam volume em passos de 5% |
| Mute de áudio | Alterna mudo da saída |
| Mute de microfone | Alterna mudo do microfone |
| Teclas de brilho | Ajustam brilho em passos de 5% |

O overlay de jogos permite ocultar sua telemetria com Shift direito + F12, mudar de posição com Shift direito + F11 e alternar registro de métricas com Shift esquerdo + F2.
